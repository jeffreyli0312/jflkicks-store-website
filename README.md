# 👟 JFL Kicks Store

A modern sneaker & apparel e-commerce website built with **Next.js** and powered by **Sanity CMS** for dynamic product management.

Designed for performance, scalability, and real-time content updates.

---

## 🌐 Live Demo

👉 https://jflkicks-store.vercel.app/

---

## 🚀 Features

- 🛍 Dynamic product listings  
- 📦 CMS-managed inventory using Sanity  
- 🧭 Category browsing & filtering  
- 🔎 Individual product pages  
- 🖼 Optimized image delivery via CDN  
- 📱 Fully responsive design  
- ⚡ Fast performance with Next.js App Router  

---

## 🧰 Tech Stack

### Frontend
- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- styled-components
- Lucide React

### CMS & Data
- Sanity CMS
- next-sanity
- @sanity/image-url

### Tooling
- ESLint
- PostCSS
- TailwindCSS
